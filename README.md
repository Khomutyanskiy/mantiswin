# Mantis для Windows

Приложение для компьютера у витрины: считает, сколько людей прошло мимо, притормозило, посмотрело и зашло — **сразу с нескольких камер**, как Mantis для Mac. Видео обрабатывается на этом компьютере и никуда не отправляется; в облако (если войти в аккаунт) уходят только цифры по часам.

## Что умеет

- **Пилот на нескольких камерах**: встроенная и USB-камеры, IP-камеры (поиск ONVIF, RTSP), телефоны Android с IP Webcam (по адресу rtsp://).
  - у каждой камеры своя разметка (зона витрины, линия прохода, вход) и чувствительность (уровень, минимальный рост, строгость «посмотрел / притормозил»);
  - сетка камер Авто / Крупно / Средне / Мелко / Мини, камера на всё окно (клик по картинке, Esc — назад), режим «во весь экран»;
  - итоги за сегодня — суммарно и по каждой камере.
- **Облако** — тот же аккаунт и та же структура Firestore, что у iPhone, Mac и веб-версии:
  - `users/{uid}/hours` — сумма всех камер по часам (видна везде);
  - `users/{uid}/camera_hours/{камера}_{день}` — по каждой камере (формат как у Mac);
  - `users/{uid}/devices/{id}` — пульс точки раз в минуту: `platform: "windows"`, кадр/с, итоги за сегодня, список камер.
- **Статистика** — по часам, дням недели и датам, оценка витрины и деньги, таблица «По камерам», какие точки сейчас считают.
- **Проверка видео** — как в веб-версии: ролик с диска, разметка, подсчёт, выгрузка JSON/CSV.
- **Для работы без присмотра**: компьютер и экран не засыпают, пока идёт пилот; камеры сами перезапускаются при сбоях; после перезапуска (и перезагрузки Windows с автозапуском) подсчёт продолжается сам; закрытие окна при идущем пилоте прячет его в трей; камера разрешена без вопросов.

## Что нового (как в Mantis для Mac, 8 ноября)

Страница приложения теперь — **mantiswebv1** (`web/`), туда перенесено всё новое с Mac:

- **Статистика** — разделы «Последний запуск», «Отчёты», «По часам и дням», «Записи двойника»: отчёт сохраняется сам при каждой остановке мониторинга (цифры по часам, камеры, оценка витрины, видео, запись двойника), список с фильтрами, сводный отчёт, удаление нескольких, PDF и Excel (CSV), сравнение периодов, фильтр по камере. Отчёты уходят в облако (`users/{uid}/reports`) — те же, что у Mac.
- **Видео по событиям** — каждая камера пишет MP4 в `%LOCALAPPDATA%\Mantis Agent\Monitoring\<запуск>\`: всё подряд или только когда в кадре люди / движение (+5 с до), размытие лиц, расписание записи, срок и объём хранения, уборка старого.
- **Двойник в облаке** — запись двойника пишется сама с каждым запуском и связана с отчётом.
- **IP-камеры** — автоподключение найденных камер (ONVIF, пути популярных марок, Android IP Webcam), подбор пароля без блокировки камеры, поворот PTZ.
- **Подсчёт** — повторное узнавание человека (ReID, 5 с), сотрудники не считаются, 7 уровней фильтра (по умолчанию «низкая»).
- **Мониторинг по расписанию** часов работы, уведомления Windows: камера пропала, картинка застыла, толпа, долгое ожидание; сон компьютера.
- **Значок в трее** — идёт ли мониторинг и сколько людей сейчас; «Запустить / Остановить мониторинг», «Отчёт последнего запуска».
- **Настройки** — хранение видео, расписание и уведомления, «не гасить экран», автозапуск, состояние системы, резервная копия настроек, пример данных, тёмная / светлая тема.
- **Первые шаги**, подсказки на экранах, **тепловая карта** разобранного видео (слои, до / после, PNG и CSV).

Команды приложения для страницы: `app_info`, `keep_awake {on, display}`, `set_autostart`, `pilot_state`, `quit_app`, `notify`, `tray_status`.

## Как устроено

```
Mantis.exe (Tauri 2, окно WebView2)
 ├─ mantis-agent.exe — встроенный агент (web/agent, Bun): страница Mantis, нейросеть, мост IP-камер, ffmpeg
 │     слушает только http://localhost:8797, пишет «MANTIS_READY port=…» — окно открывает страницу
 └─ страница = web/ с ?desktop=windows → вкладка «Пилот» на нескольких камерах (web/src/multi)
```

| Файл | Что делает |
|---|---|
| `src-tauri/src/lib.rs` | запуск агента, команды для страницы (`app_info`, `keep_awake`, `set_autostart`, `pilot_state`, `quit_app`), разрешение камеры в WebView2, запрет сна, трей, один экземпляр, автозапуск |
| `src-tauri/tauri.conf.json` | окно; фоновое замедление WebView2 выключено (подсчёт не тормозит в свёрнутом окне); установщик NSIS |
| `src-tauri/capabilities/default.json` | странице с `http://localhost:*` разрешены только команды приложения |
| `scripts/build-agent.mjs` | собирает страницу и агента в `src-tauri/binaries/mantis-agent-x86_64-pc-windows-msvc.exe` |
| `splash/index.html` | заставка, пока стартует агент; ошибка запуска показывается здесь |
| `../web/src/multi/` | пилот на нескольких камерах: камеры, модель, чувствительность, статистика по камерам, экран |
| `../web/src/desktop.ts` | связь страницы с приложением (в обычном браузере ничего не делает) |

Веб-версия в браузере и iPhone остаются на одной камере: экран нескольких камер включается только внутри приложения.

## Сборка

### Через GitHub Actions (рекомендуется)

Workflow собирает установщик на `windows-latest`. Его файл лежит в `mantiswin/ci/mantiswin.yml` — один раз перенесите его в `.github/workflows/` в корне репозитория:

```bash
mkdir -p .github/workflows && mv mantiswin/ci/mantiswin.yml .github/workflows/
```

Дальше он запускается:

- вручную: Actions → «Mantis для Windows» → Run workflow;
- сам при изменениях в `web/` или `mantiswin/` в ветке `main`;
- по тегу `win-v0.1.0` — установщик прикладывается к релизу.

Результат: артефакт `Mantis-Windows` → `Mantis_0.1.0_x64-setup.exe`.

### На компьютере с Windows

Нужны Node 22, Bun 1.4, Rust (stable, MSVC) и Visual Studio Build Tools (C++).

```powershell
cd web;       npm ci --ignore-scripts
cd ..\mantiswin; npm ci
npm run build          # агент + приложение → src-tauri\target\release\bundle\nsis\Mantis_0.1.0_x64-setup.exe
```

### Разработка на Mac

`npm run dev` собирает агента под Mac и открывает окно Tauri (WKWebView). Код, специфичный для Windows (WebView2, запрет сна), на Mac не работает, остальное — как в Windows.

## Установка у клиента

1. Запустить `Mantis_0.1.0_x64-setup.exe` (ставится для текущего пользователя, права администратора не нужны). Установщик не подписан — SmartScreen: «Подробнее» → «Выполнить в любом случае». Если в системе нет WebView2 (Windows 10 без обновлений), установщик скачает его сам.
2. Брандмауэр спросит про сеть — разрешить для частных сетей (иначе IP-камеры не найдутся).
3. В приложении: войти в аккаунт → «Добавить камеру» → разметить → «Запустить пилот». Внизу экрана — «Запускать при входе в Windows».

Журнал агента: `%LOCALAPPDATA%\Mantis Agent\agent.log`. Настройки камер и вход хранятся в профиле WebView2 приложения (`%LOCALAPPDATA%\ru.rsmit.mantis`).

## Ограничения

- Одна нейросеть на все камеры: частота на камеру — 15 кадр/с при 1–2 камерах, 10 при трёх, 8 при четырёх и больше (как на Mac); фактическая зависит от видеокарты (WebGPU) или процессора.
- Порт 8797 должен быть свободен: настройки камер привязаны к адресу страницы. Если он занят, агент возьмёт следующий, и камеры придётся добавить заново.
- Зоны исключения и «неподвижные фигуры» из чувствительности Mac пока не перенесены.
- Подпись кода (чтобы не было предупреждения SmartScreen) — отдельный сертификат.
